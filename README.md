# SafeScroll AI 🛡️

SafeScroll AI is a lightweight AI-powered system for detecting and filtering offensive comments in **Tamil, English, and Tamil-English code-mixed text**.

It uses a **Character-level TF-IDF + Linear SVM** machine learning model to classify comments into different offensive-content categories.

The project includes:
- 🤖 Machine Learning model for comment classification
- 🔌 Flask REST API for predictions
- 💻 React-based web dashboard
- 🌐 Chrome extension for analyzing and filtering YouTube comments

SafeScroll AI aims to make online spaces safer by helping users identify potentially offensive content in Tamil-English code-mixed social media comments.
